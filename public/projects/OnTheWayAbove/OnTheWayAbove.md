<h2 style="text-align:center;">About the Project</h2>

<p align="justify">
<i>On the Way Above</i> is a 2D <b>action platformer roguelike</b> that combines fast-paced combat, procedural level generation, and escalating difficulty over time. Set a hundred years after a cataclysmic event that nearly eradicated humanity, the world is now overrun by rogue AI and hostile machines. Players must fight to survive against increasingly difficult enemies while exploring a dynamically generated world.
<br><br>
The objective is to survive as long as possible and aim for the highest score. Enemies grow stronger over time, encouraging the player to collect powerful items and level up their character. Each run features procedurally generated stages for maximum replayability.
<br><br>
The game was developed using <b>Unity</b> and draws heavy gameplay inspiration from <i>Risk of Rain</i> and procedural generation design from <i>Spelunky</i>. The next major goal for the project is to implement 4-player online co-op.
</p>

<p align="justify">
I contributed to the project as both a <b>Gameplay and UI Programmer</b>. My responsibilities included:
<ul>
<li>Developing a seed-based procedural stage generation system using techniques such as cellular automata.</li>
<li>Designing and implementing stat scaling systems for both the player and enemies to support progressive difficulty.</li>
<li>Programming all core gameplay systems, including combat, movement, and stage interactions.</li>
<li>Creating item-based roguelike mechanics, including item spawning, stacking, and character effects.</li>
<li>Implementing user interface and user experience (UI/UX) features such as HUD elements, menus, and game feedback.</li>
<li>Planning and developing the foundation for online multiplayer using Unity's Netcode for GameObjects (co-op mode coming soon).</li>
</ul>
